# Barangay Management Information System

A responsive Barangay Management Information System for managing residents, households, documents, officials, announcements, barangay services, reports, and administrative activity.

## Planned Modules

- Dashboard
- Residents
- Households
- Documents
- Officials
- Announcements
- Barangay Services
- Reports
- Activity Log
- Responsive mobile and tablet interface
- Admin authentication
